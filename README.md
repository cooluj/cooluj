## Featured Projects

### Eventully · Club discovery for UW

<a href="https://eventully.org"><img src="https://img.shields.io/badge/Live-eventully.org-6d28d9?style=flat-square&logo=rocket&logoColor=white" alt="Live site" /></a>
<a href="https://github.com/cooluj/Eventully-Project"><img src="https://img.shields.io/badge/Source-cooluj%2FEventully--Project-181717?style=flat-square&logo=github&logoColor=white" alt="Source repository" /></a>

Production Flask platform I founded in June 2024 and have run since. Students find their community across 1,231 UW student organizations; club officers claim listings, post events, manage RSVPs, and message members. **2,000+ users · 200+ events.**

- **Matching that explains itself.** Ranks all 1,231 organizations in under 200 ms with a weighted scoring pipeline over category, major, and time-commitment signals. Every match returns a score, the reasons behind it, and a badge.
- **Real auth and multi-tenancy.** Role-based access across 3 user types, .edu-verified sign-up, hashed passwords, email verification and password reset, and an admin approval flow for claiming a club.
- **Engineered to run.** 53 automated tests, an admin launch-readiness page that checks the database, mail config, and leftover demo data, SQLite to PostgreSQL by a single environment variable, and a scheduled GitHub Action that keeps the Render deploy warm. Page loads cut 45% through query and asset optimization.

`Python` `Flask` `SQLAlchemy` `PostgreSQL` `JavaScript` `Gunicorn` `Render` `GitHub Actions`

### PainSights · Clinical AI dashboard for nonverbal patients

<a href="https://devpost.com/software/painsights"><img src="https://img.shields.io/badge/Devpost-FigBuild%202026-7c3aed?style=flat-square&logo=devpost&logoColor=white" alt="Devpost, FigBuild 2026" /></a>
<a href="https://www.figma.com/proto/3qsWtlluXq8KKnCkaAjHPk/PainSights?node-id=0-1"><img src="https://img.shields.io/badge/Prototype-Figma-6366f1?style=flat-square&logo=figma&logoColor=white" alt="Figma prototype" /></a>

Pain is only ever self-reported, and some patients cannot report it. PainSights reads a pain signal from a sensor and renders it on a body model so a clinician can see where it hurts and how much. Built with a team of three at FigBuild 2026, Figma's student design-a-thon, and presented there.

- Designed the clinical dashboard from patient queue to per-patient report: patients prioritized by urgency, detected pain points ranked by severity
- Prototyped AI-assisted pain-scoring workflows, demoed with a 3D-printed mock EEG headset

`React` `Figma` `Clinical AI` `Data Visualization`

<a href="https://cooluj.github.io/Portfolio/"><img src="https://img.shields.io/badge/Live-GitHub%20Pages-6d28d9?style=flat-square&logo=github&logoColor=white" alt="Live preview" /></a>
